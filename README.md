<h1 align="left">Quviu</h1>

Quviu (**Qu**ick **vi**deo **u**tilities) is an easy-to-use GUI for FFmpeg that allows you to quickly re-encode and trim video files.

> [!WARNING]
> **Work in Progress 🚧:** This program is in its early stages of development. Expect bugs and missing features.

## Build from source

### Install

```bash
$ pnpm install
```

### Development

```bash
$ pnpm dev
```

### Build

```bash
# For windows
$ pnpm build:win

# For macOS
$ pnpm build:mac

# For Linux
$ pnpm build:linux
```
